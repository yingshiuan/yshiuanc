This repository contains the source for my personal website, built with the
[Lektor CMS](https://www.getlektor.com/). The site showcases my portfolio,
projects, resume, and contact information.

## What's included

- Static site source managed with Lektor
- Portfolio project pages (see `portfolio/`)
- Resume and contact pages
- Static assets (CSS, JS, images) in `static/`

## Quick overview

This repo is the canonical source for the website content and templates. It
contains the content folders and static assets used to build the site.

## Development (local)

To preview or edit the site locally, install Lektor and run the local server
from the project root. Edit content files and templates, then refresh the
server to see changes.

## Repository links

- Current site source (this repo): https://github.com/yingshiuan/yshiuanc
- New framework / migration repo: https://github.com/yingshiuan/yingsc

Clone commands (pick one):

```bash
# clone the current site source
git clone https://github.com/yingshiuan/yshiuanc.git

# clone the new-framework / migration repo
git clone https://github.com/yingshiuan/yingsc.git
```

## Project structure (high level)

- `about-me/`, `contact/`, `portfolio/`, `resume/` — content pages
- `static/` — CSS, JS, and other static assets
- `index.html`, `sitemap/`, and other top-level files used by the site
